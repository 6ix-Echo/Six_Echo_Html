# Six-Echo 页面 QA 清单

## 内容

- [ ] 主题标题、主讲人和身份标签准确。
- [ ] 六角色系统包含 LLM、RAG、Agent、Harness、Skill、MCP。
- [ ] Harness 位于 Agent 之后，并有生活化例子。
- [ ] Prompt 五段式和完整样例没有被省略。
- [ ] Skill 样例按类别展示，条目没有被无意删减。
- [ ] 讲者提示可展开且不压过正文。

## 视觉

- [ ] 主背景白色区域没有被整体染成暖色。
- [ ] 彩色元素以横条/角标为主，没有无意义色块堆叠。
- [ ] 章节标题为深色，正文对比度足够。
- [ ] 图片不超过内容板宽，照片有边框和留白。
- [ ] 四格漫画人物不露脸、保持天狗面具和自然身材比例。
- [ ] 手机端没有横向滚动和文字遮挡。

## 交互

- [ ] 头像卡可以点击和键盘翻转。
- [ ] tab 的 `aria-selected`、`hidden` 状态正确。
- [ ] Prompt 复制按钮有成功/失败反馈。
- [ ] 所有按钮和链接有 focus-visible。
- [ ] reduced motion 下没有强制动画。

## 发布

- [ ] 根目录有 `index.html`。
- [ ] `assets/` 中所有引用文件存在。
- [ ] 不上传 tests、node_modules、草稿资料或私密文件。
- [ ] GitHub Pages 或 Vercel 访问路径使用相对资源。
